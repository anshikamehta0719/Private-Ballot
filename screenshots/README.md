# Screenshots

Add these before submitting (referenced from the main README):

1. `test-output.png` — terminal output of `npm test` showing all 6 tests
   passing (satisfies the "3+ tests passing" requirement).
2. `ci-run.png` (optional but recommended) — a green run of the GitHub
   Actions workflow from the repo's Actions tab.
3. `compile-output.png` (optional) — output of `npm run compact` listing
   the compiled circuits (`castVote`, `closeVoting`, `tally`).
4. `app-screenshot.png` (optional) — the running frontend: wallet
   connected, vote cast, tally updated.
